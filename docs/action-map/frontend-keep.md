# Frontend to keep

What the Claude stack #73 to #134 built in `apps/desktop/src`, `packages/ui`, and `packages/lib`, and what the new core work must not undo. Read from the PR bodies, the `docs/spec-native-feel-*.md` files, and the area files on 2026-09-17.

## The rule

The frontend has no business rule and no knowledge of harness disks. It renders the snapshot, sends one IPC call per user action, and applies events. So the rebuild changes the Rust side only. `apps/desktop/src/lib/skill-api.ts` is the one file that maps a wrapper name to a Tauri command. When a command is replaced by an `ops` function, the wrapper keeps its name and its return type, or the component that calls it changes in the same PR with a test. No component learns a new command name by hand.

## Gaps

- `events-and-history.md` describes the Activity view before #130.

`apps/desktop/src/lib/skill-api.test.ts` (unit 4.4, #175) is the standing guard: it pins every skill-api.ts wrapper to its command string, cross-checks that against `src-tauri/src/lib.rs`'s `generate_handler!` list read off disk, and fails by naming the wrapper or command that drifted. Change a wrapper's name or command string only with an update to that file in the same PR.

- Bulk actions in the selection bar are a placeholder with no command behind them.
