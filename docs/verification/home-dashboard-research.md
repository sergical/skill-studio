# What belongs on Skill Studio’s Home

Someone who has installed a skill still has two questions. Did an agent load it during recent work? Did that client receive enough of its description to choose it? Skill Studio can answer both across clients from local records. A folder scan, a listing preview, a captured listing and a recorded load each answer a different part of the question.

| Evidence                                                                                                                                                                                                                      | What it implies for Home                                                                                                                                              |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| In two fresh Claude Code sessions, a user found that 27 of 36 project skills arrived by name alone. Explicit invocation still worked. [Claude Code listing report](https://github.com/anthropics/claude-code/issues/81081)    | Show what was found on disk beside the predicted descriptions and the last recorded listing. Name the source of each count and let the reader open the client report. |
| A Codex user wanted a way to see which skills and tools ran during a task without rereading the conversation. [Codex task history request](https://github.com/openai/codex/issues/33720)                                      | Put recent recorded loads on Home. A day opens Activity for that date. An installed skill in the ranking opens its own page.                                          |
| In Vercel’s Next.js evaluation, the agent skipped the available skill in 56% of cases. That figure describes their test suite. [Vercel’s experiment](https://vercel.com/blog/agents-md-outperforms-skills-in-our-agent-evals) | Call the measure “recorded skill loads.” An absence of records cannot establish that a skill failed, or that removing it would improve results.                       |

The trend and the most-used skills share one date control so the counts describe the same period. Vercel’s analytics screen was a reference for this arrangement. Library repairs sit below client visibility, with each affected name opening the skill. [Analytics reference on Mobbin](https://mobbin.com/screens/f58e584d-9481-4125-961f-b08bde53529b)

The working design opens in the native Home Lab app. **Compare designs** keeps Repairs, Clients and Recent work available. A useful usability check is to ask a skill author to find a recently used skill, then check whether another client received its description. The reports above support the questions. Observing someone try that sequence would test the layout itself.
