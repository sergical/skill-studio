# OpenCode and pi skill guidance

Verified November 23, 2026 on macOS using OpenCode 2.3.2 and pi 1.6.0. The disposable homes had ordinary project and user skill folders, two copies of a release skill, a manual-only skill and Vercel’s public web-design-guidelines skill installed with npx. Both clients wrote their own session records with a loopback-only model endpoint. No provider credentials or successful model response were required.

| User-visible result  | Client evidence                                                                                                                                              | Skill Studio result                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| OpenCode plan agent  | 5 entries in its current skill guidance blob. The plan agent denied verify-packaging and the manual-only skill was absent.                                   | All 5 IDs, names and descriptions matched.                                                                                          |
| OpenCode build agent | 7 entries after enabling the manual skill with the numeric auto-invoke override. The build agent permitted verify-packaging.                                 | All 7 IDs, names and descriptions matched. Its folder scan found 5 local skills. Two bundled skills were present in saved guidance. |
| pi trusted project   | ResourceLoader found 5 names. Its formatter included 4, preferred the project release skill and used the project symlink’s path for the shared Vercel skill. | The full base prompt skills section matched byte for byte, including XML entities and locations. Budget was null.                   |
| pi saved sessions    | One saved system message included the four skills. Continuing another session with skills disabled appended a null skills patch.                             | The session reports contained 4 and 0 entries respectively.                                                                         |

The desktop runtime and CLI produced identical listing rows, session rows, summaries and per-skill counts for both clients. The desktop UI was also exercised in WebKit and Chromium. Screen Recording and Accessibility were unavailable to the worker on the Mac.

OpenCode guidance describes the latest saved state for that session. pi's preview assumes default skill folders, a trusted project and the read tool. Its saved structured section can differ from a provider request if an extension forces a different prompt. Unrecognized sections or unresolved blobs are reported as unavailable.
